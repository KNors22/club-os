# v1.3.0 — Actionable dashboard

Released October 31, 2026.

Administrator cards now open all members, active-only members, or events. Payments received selects Payments in Club insights, moves keyboard focus and scrolls to the graph. Member status, search and pagination are shareable URL state that survives reload and browser history. Reduced-motion preferences are respected.

Only alex, jordan, taylor, morgan, maya, noah, olivia and ethan appear as login sample choices, all with @clubos addresses. The full seeded member dataset remains in club records.

Validation: 100 component/API tests, lint, types, builds, both compiled smoke checks and ten Chrome/Firefox scenarios pass in isolated snapshots. Atlas contains the v1.2 historical dataset and a private backup is saved. Post-publication verification on October 31 confirmed the four live card actions, active-filter reload, payment-graph focus/scroll, eight login choices, mobile layout, six clubs and 2010 payment history. Read-only live readiness also passes. The full production-write walkthrough remains unverified. Email integration is a future feature that has not been completed; preliminary transport code and mocked tests do not constitute a delivered integration. Notifications are disabled.

# v1.1.0 — Membership cards

Released October 31, 2026.

Members can save a PNG card from **My membership** containing their name, full club name, membership ID, validity, expiration time, and status. The image uses the current authenticated membership at save time and refreshes the page after renewal. No scanning is required.

Unpaid memberships need activation before a card is available. Expired memberships produce clearly expired cards. Saved cards are static copies; members should save a new one after renewal. Cards include no email, join code, or payment information.

The release consists of focused API, member-interface, browser-validation, and release-documentation commits. Root/client/server and lockfile versions align at 1.1.0. Existing user-staged edits remain separate.

Validation: 88 component/API tests (26 frontend, 62 backend), lint, type checks, production builds, compiled-server and Render startup/restart smoke checks, and ten Chrome/Firefox scenarios. The browser suite checks actual 2160×1360 PNGs, fresh renewal dates, expired/unpaid behavior, long names, and responsive layouts. These checks run from isolated prospective-commit snapshots. Live verification follows publication.

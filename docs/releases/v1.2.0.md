# v1.2.0 — Historical club records

Released October 31, 2026.

The sample dataset includes 48 people, six clubs, 212 memberships, 465 events and 1,150 payments on a fresh October 31, 2026 database. Annual renewals start in 2010. It includes current membership states, monthly activity, future events, registrations and attendance. Existing records can produce different totals because edits and histories are preserved.

Accounts use `firstname@clubos` and natural names. The original five identities keep their IDs, with conditional address/default-label migration. The login selector exposes all accounts. `npm run seed` initializes the same dataset used by Render startup; public password/environment settings remain compatible.

A saved reference date, fixed IDs, insert-only writes and preflight checks support safe repeat runs and missing-record recovery. Existing joined relationships survive. Seeding sends no emails and provides no reset command.

Validation: 98 component/API tests, lint, types, builds, both compiled smoke checks and ten Chrome/Firefox scenarios pass. Live verification follows publication.

# v1.0.0 — Club insights and readable navigation

The administrator overview now visualizes the club's recorded memberships, attendance, payments, and upcoming events. The navigation and footer complete the major release's layout improvements.

## Changes

- Membership-status donut, active-member share, cumulative member-growth line, and attendance/payment trends.
- Six/twelve-month controls, keyboard/hover values, expandable data tables, and useful zero-data states.
- The next four events with dates, locations, registered counts, capacity bars, and working detail links.
- Wider desktop navigation, a roomy scrollable mobile drawer, and full club/header names that wrap instead of truncating.
- Shared author credits: Andrey Gonzalez, current year, and [GitHub profile](https://github.com/KNors22).

Analytics remain administrator-only and organization-scoped. Monthly totals use Eastern Time; growth counts joined records, current status uses membership validity, attendance uses check-in timestamps, and payment trends use received dates. Existing membership/payment/event workflows and the public demo credentials remain compatible.

## Validation

79 component/API tests, production compilation, both compiled server/startup-restart smoke checks, and ten installed Chrome/Firefox scenarios passed from isolated snapshots. Actual [desktop](../screenshots/v1-dashboard-desktop.png), [mobile](../screenshots/v1-dashboard-mobile.png), and [sidebar](../screenshots/v1-sidebar-mobile.png) captures document the layout. CI and live verification follow publication.
